# Votera — Definition of Done

A feature is Done when:

- Requirement is clearly identified.
- User story and acceptance criteria are understood.
- UI is implemented where required.
- Backend logic is implemented where required.
- Database changes are complete where required.
- Validation is implemented.
- Authorization is implemented.
- Relevant tests pass.
- Manual verification is completed where appropriate.
- No known critical security issue remains.
- Documentation is updated where necessary.
- Code is committed.
- Pull request review is completed where applicable.
- Feature is merged.
- Release notes are updated when required.
